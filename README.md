WiSCode is a fast, native code editor written in Rust, with a clean, modern design and coding agents built in. WiSCode is a fork of [Zed](https://github.com/zed-industries/zed) but diverges heavily from it.

## Features

- ⚡ **Native and fast.** No Electron or webviews. Opens instantly and stays responsive on large views.
- 🍃 **Lightweight.** WiSCode's memory footprint is lower than VS Code and Zed. See [benchmarks](https://github.com/WallisSkill/ide-clone-wu/blob/main/docs/memory-benchmark.md).
- 👾 **Coding agents included.** Built-in support for Claude Code, Codex, and OpenCode.
- ✨ **Beautiful by default.** Clean, modern look with a delightful UX.
- 🤫 **Completely Private.** No account or telemetry. WiSCode never sends your usage data anywhere.

## Download

For Windows, download the [WiSCode installer](https://github.com/WallisSkill/ide-clone-wu/releases/latest/download/WiSCode-x86_64.exe).

All versions are on the [Releases](https://github.com/WallisSkill/ide-clone-wu/releases) page. For Java support, install the [java-wis extension](https://github.com/WallisSkill/java-extention-for-wu-clone).

See [INSTALL.md](https://github.com/WallisSkill/ide-clone-wu/blob/main/docs/INSTALL.md) for more.
